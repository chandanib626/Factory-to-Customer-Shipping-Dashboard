# Factory-to-Customer Shipping Dashboard

## Project Overview

This project analyzes shipping efficiency between factories and customers for Nassau Candy Distributor. The dashboard helps identify shipping delays, route performance, regional trends, and delivery efficiency.

## Features

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Shipping Delay Analysis
- Route Performance Analysis
- State-wise Analysis
- Interactive Streamlit Dashboard

## Technologies Used

- Python
- Pandas
- NumPy
- Plotly
- Streamlit
- Jupyter Notebook
